# Loop / branch synchronization visualization

Static research demonstration: work correspondence, barrier generation matching,
resource completion coverage, and measured native HB query reuse.

Open `index.html` using a static HTTP server; `report.pdf` contains the research note.
The page embeds its fixed-input native verification evidence. It does not execute
GPU kernels or submit visitor input to a server. Notes stay in the visitor's browser.

Published September 18, 2026. Constructed protocol; no full upstream-kernel or
arbitrary-iteration safety claim. This repository is independent of existing sites.
