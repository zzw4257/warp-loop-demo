RULE VIEW

Keep the skeleton. Own the optional effects.

Illustrative rule diagram, not an extracted path or computed verdict from the running example. The actual h64/h128 checks are in Corpus.

common skeleton+endpoint-owned optional effects→support(path) ⊆ owners(endpoint A) ∪ owners(endpoint B)
provedall required support is common or endpoint-owned
unproveda required relation is missing under the selected choices
rejecteda stated premise, such as fixed footprint, is false

A proved ordering is not numerical equivalence. Unproved is not a kernel bug. Tensor feedback, arbitrary loop length, and unresolved footprint remain outside this rule.
