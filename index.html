THE QUESTION

When a loop iteration skips asynchronous work, which ordering arguments still survive?

A buffer can be reused only after its old readers finish. If a branch removes an operation or a wait, the original ordering argument needs to be checked again.

Existing Wasp capabilityFor a supplied control path, Wasp builds dynamic events and checks synchronization and races under its model. The corpus h64 input fixes rescale to execute.
Our added analysisCheck a finite family of execute/skip choices together. Preserve the common synchronization structure, and accept an ordering argument only when it does not require an unrelated optional region to execute.

OUR METHOD · RECORDED H64 CHECK

Which optional work does an ordering argument need?

Each owner is one warp at one branch visit. For a pair of conflicting accesses, use only common events and optional work owned by those endpoints. A third owner's optional work may be skipped, so it cannot be necessary to that argument.

Admission first checks unchanged common control, resolved addresses, valid collective participation and completion obligations.
